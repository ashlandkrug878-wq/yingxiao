# 造梦体系：内容电商四个段位 + 01–07 造梦路径

方法论来源：讲者迪安的两段内容，一段是内容电商四个段位的自述，一段是给一个 39 元陈皮类口喷做的小红书连麦咨询。核心观点：内容电商的起点不该是"什么内容容易爆"，而是品牌的核心人群是谁、在过怎样的生活、有什么没说出口的情绪、想成为怎样的人。

## 使用方式

1. **先定段位**：判断团队处在四个段位中的哪一个，指出这个段位该做和不该做的事。
2. **按 01 → 07 找卡点**：对照每一步的完成标志，找出第一个没做到的步骤。
3. **给动作**：输出卡点这一步最该做的事。涉及人群和内容时，直接给出 2–3 个人群切片，每个切片配一句难言之隐、一句向往画面、一条示例标题。

- 默认在对话里直接给结论和建议，用户明确要求时才生成文档或方案表。
- 信息不够时，先像讲者一样问清三件事：对方的角色、背的指标、营销费多少；再问产品的候选人群和现有笔记的样子。最多问 3 个问题，其余先做合理假设并说明。
- 平台默认是小红书。用于抖音时，说明哪些判断需要重新验证。
- 配套的自诊断网站数据在 yingxiao 仓库 `methodologies/dream-system/diagnosis.json`，两者内容需保持一致。

## 内容电商四个段位

| 段位 | 做法 | 问题 |
|---|---|---|
| 第一段位 | 借外部达人的账号和流量，达人自己想选题、写脚本；考核爆文率、CPC、CPE | 达人很难自然出爆款，还要另外花钱投流 |
| 第二段位 | 借壳生子：仍用外部达人，但选题、脚本、封面、标题、评论区由品牌强把控，达人只是演员 | 流量仍在别人的账号上 |
| 第三段位 | 内容资产自有化：品牌号、员工号、素人号矩阵 + 内容中台 | 每个品和人群割裂、从零开始，没有复购；爆了就被抄；想转品牌时去找明星 |
| 第四段位 | 造梦体系：从原点人群出发 | — |

## 01 原点人群：从人出发，不从爆款出发

- 品牌的核心人群是谁，他在经历怎样的生活，有没有没说出口的情绪，想要怎样的状态，想成为怎样的人。
- 完成标志：团队对"我们为谁做内容"有同一个答案。

## 02 人群切片：切到一个具体的人和他的某个时刻

- 把原点人群切成具体的切片，例如"夜里被孩子清嗓子惊醒的照护者"。
- 用竞品近几个月在不同人群上的投放和笔记趋势判断哪个人群更痛：案例中用嗓职业人群的竞品投放在下降、儿童人群在上升，于是优先打宝妈。
- 看需求集中在哪些季节或触发场景（案例中是秋冬换季、降温、开空调）。
- 预防、提前准备型的切片，人群基数比已经出问题的切片更大，可以重点打。
- 完成标志：能说出 2–3 个具体切片，并说明为什么先打其中一个。

## 03 情绪：难言之隐和向往

- 大部分竞品打的是"人群 + 场景"，很少打情绪，这是差异化的机会。
- 难言之隐：说不出口的困扰。向往情绪：问题解决后想要的状态。
- 焦虑可以有，但更要描绘问题解决或准备好之后的正面画面，例如"我能把孩子照顾好"的全能妈妈心理。
- 完成标志：每个切片都有一句难言之隐、一句向往。

## 04 理想画面：用封面、标题、文案构建向往

- 通过封面、标题、文案描绘用户向往的生活画面，让每条内容都能看到品牌的影子。
- 科普大字报只能吃搜索流量，进不了发现页，转化低，而且已经高度同质化；产品硬照做封面太硬，拿不到流量。
- 借鉴爆款只借元素，不整条拆解复制，否则内容和竞品差不多，流量会越来越差。
- 完成标志：笔记能进推荐页拿流量，而不只靠搜索。

## 05 自有账号跑通：先在自己的账号上闭环

- 用品牌号、员工号、素人号等自有账号，跑通从种草、心动到下单的闭环，沉淀内容资产和人群资产。
- 完成标志：至少一个切片在自有账号上稳定出单。

## 06 分发放大：再交给达人、KOC、素人

- 自有账号跑通后，再通过达人、KOC、素人分发。
- 选题、脚本、封面、标题、评论区由品牌把控，达人是演员，不依赖达人自己想内容。
- 完成标志：外部达人的内容和自有账号一样能出单。

## 07 围绕原点人群开新品：让用户认得出品牌、愿意复购

- 每个新品都围绕同一个原点人群开。第一个品爆了之后，用户对品牌有辨识度，新品会被复购；否则每个品都从零开始，能不能爆全靠概率。
- 完成标志：新品的首批用户里有相当一部分来自老用户。

## 输出结构（诊断时默认采用）

1. **所处段位**及判断依据，这个段位该做和不该做的事。
2. **卡在第几步**：01–07 中第一个没做到的步骤，以及还缺什么。
3. **人群切片表**：2–3 个切片，每个配难言之隐、向往画面、一条示例标题和封面描述；说明建议先打哪个及理由。
4. **最该做的 3 件事**（具体到动作）。
5. **需要警惕的风险**，包括合规风险。

## 使用时的提醒

- 连麦案例只有建议、没有执行结果，实操部分要当待验证的假设。
- 自述中"半年内用 10% 营销费让多个品做到 TOP1"无法核实，内容里有招聘、引流话术。
- 平台以小红书为主，换到抖音要重新验证。
- 讲者批评的"第一段位"是让达人自由发挥、只看爆文率，不是否定达人投放本身。
- 儿童健康、保健类产品写理想画面时，不能写成预防、治疗等功效承诺，要守住广告合规红线。
