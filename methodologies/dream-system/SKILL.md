# 造梦体系：直接套用的品牌内容方案框架

方法论来源：讲者迪安的两段内容，一段是内容电商四个段位的自述，一段是给一个 39 元陈皮类口喷做的小红书连麦咨询。核心观点：内容电商的起点不该是"什么内容容易爆"，而是品牌的核心人群是谁、在过怎样的生活、有什么没说出口的情绪、想成为怎样的人。

这个 skill 的主要用途是**套框架出方案**：用户给出一个品牌或产品，按下面的框架直接产出一套造梦方案。判断团队处在哪个段位是次要的，只在用户问到、或者团队的做法明显卡在某个段位时附上。

## 使用方式

1. **收集输入**：品牌和产品是什么、价格、主要平台、已知的候选人群、主要竞品。信息不够时最多问 3 个问题，优先问候选人群和竞品；其余先做合理假设，并在方案开头写明假设。
2. **按框架逐步产出**：严格按下面"方案框架"的六部分输出，每一部分都给出能直接用的内容，而不是只讲原则。
3. **对照避坑清单自查**，再交付。

- 方案默认在对话里直接给出；用户明确要求时才生成文档或表格文件。
- 平台默认是小红书。用于抖音时，标题、封面、流量入口的判断要说明需要重新验证。
- 用户有多个品牌或产品时，每个产品单独出一套，最后说明它们能否共用同一个原点人群。

## 方案框架

### 一、原点人群

用三句话写清：
- 他是谁（年龄段、身份、家庭或工作状态）；
- 他在过怎样的生活，和产品有关的是哪些时刻；
- 他想要怎样的状态、想成为怎样的人。

原则：从人出发，不从"什么内容容易爆"出发。

### 二、人群切片表

把原点人群切成 3–5 个切片，每个切片是"一个具体的人 + 他的一个具体时刻"，例如"夜里被孩子清嗓子惊醒的照护者"。用表格输出：

| 切片 | 触发时刻或场景 | 难言之隐 | 向往画面 | 痛感和规模判断 | 优先级 |
|---|---|---|---|---|---|

切片和排序的规则：
- **痛感**：看竞品近几个月在不同人群上的投放和笔记是升是降；竞品在加投的人群通常更痛。用户没提供竞品数据时，写出要去查什么、去哪查。
- **时刻**：写出季节、天气、生活节点等触发时刻，例如秋冬换季、降温、开空调。
- **规模**：预防、提前准备型的切片，人群基数通常比"已经出问题"的切片更大，优先考虑。
- **差异**：竞品大多在打"人群 + 场景"，切片要落到情绪上才能拉开差异。
- 最后写明建议先打哪个切片，以及理由。

### 三、情绪和理想画面

对优先级最高的 1–2 个切片：
- **难言之隐**：一句话，写用户说不出口的困扰（例如孩子一直清嗓子，自己整晚睡不好，第二天还要上班）。
- **向往画面**：一句话，写问题解决或准备好之后的状态（例如孩子和自己都睡个好觉）。
- **身份感**：一句话，写用户因此成为了怎样的人（例如"我能把孩子照顾好"的全能妈妈）。
- 焦虑可以出现，但内容的落点必须是向往画面，不能只放大焦虑。

### 四、内容包

对每个优先切片，给出可以直接拿去做的内容：
- **标题** 3 条：描绘向往画面或说中难言之隐，不写成科普标题或产品名标题。
- **封面** 2 个：描述画面里有谁、在什么时刻、是什么状态；不要用产品硬照或科普大字报。
- **正文结构**：开头说中难言之隐 → 描绘向往画面 → 产品作为实现画面的方式自然出现 → 结尾回到身份感。
- **评论区引导**：1–2 条品牌可以主动运营的评论方向。
- **与竞品的差异**：一句话说明这组内容和竞品主流内容的区别。
- **可借鉴的爆款元素**：只列元素（画面、句式、节奏），不整条照搬。

### 五、账号和分发计划

1. **自有账号先跑**：用品牌号、员工号或素人号，先发哪个切片的内容，发多少条，用什么判断跑通（笔记能进推荐页而不只靠搜索、种草到下单的转化）。
2. **再交给达人分发**：跑通后，把验证过的切片写成给达人、KOC、素人的选题和脚本；选题、脚本、封面、标题、评论区由品牌把控，达人只当演员。
3. **分发顺序**：先小规模验证，再放大；写明每一轮放大的条件。

### 六、新品延展

- 列出同一原点人群在其他时刻还有哪些需求，作为新品方向（2–3 个）。
- 说明新品如何沿用同一套切片和画面语言，让老用户认得出品牌、愿意复购。

## 避坑清单（交付前自查）

- 主力内容是不是科普大字报？只能吃搜索流量，进不了推荐页。
- 封面是不是产品硬照？太硬，拿不到流量。
- 是不是整条拆解、复制了某条爆款？只能借元素。
- 是不是只在打焦虑？落点必须是向往画面。
- 达人内容是不是交给达人自由发挥？选题、脚本、封面、标题、评论区要由品牌把控。
- 新品是不是和原点人群割裂？
- **合规**：儿童健康、保健、食品类产品的画面和标题，不能写成预防、治疗等功效承诺，例如"换季不再感冒"。向往画面写状态和感受，不写疗效。

## 附：内容电商四个段位（次要，按需使用）

只在用户问到、或者团队做法明显卡在某个段位时附上：

| 段位 | 做法 | 问题 |
|---|---|---|
| 第一段位 | 借外部达人的账号和流量，达人自己想选题、写脚本；考核爆文率、CPC、CPE | 达人很难自然出爆款，还要另外花钱投流 |
| 第二段位 | 借壳生子：仍用外部达人，但选题、脚本、封面、标题、评论区由品牌强把控，达人只是演员 | 流量仍在别人的账号上 |
| 第三段位 | 内容资产自有化：品牌号、员工号、素人号矩阵 + 内容中台 | 每个品和人群割裂、从零开始，没有复购；爆了就被抄；想转品牌时去找明星 |
| 第四段位 | 造梦体系：从原点人群出发 | — |

## 参考案例：39 元陈皮类口喷（连麦咨询）

- 背景：母婴大品牌旗下的新品，但不能借大品牌宣传，等于白牌；目标半年内小红书月销 100 万。
- 选人群：候选是换季时孩子的宝妈、用嗓的职业人群。竞品在用嗓人群上的投放在下降、在儿童人群上在上升，优先打宝妈；换季需求集中在秋冬。
- 内容问题：品牌号的科普大字报只吃搜索流量；种草号封面是产品图，太硬。
- 切片：夜里被孩子清嗓子惊醒的照护者；换季提前准备的人（建议重点打）；怕处理过度又怕耽误的谨慎型家长。
- 画面：不只打焦虑，描绘"我能把孩子照顾好"的全能妈妈。

这是咨询建议，没有执行结果，套用时要当待验证的假设。

## 使用时的提醒

- 连麦案例只有建议、没有执行结果，框架的实操部分要在自有账号上先验证。
- 自述中"半年内用 10% 营销费让多个品做到 TOP1"无法核实，内容里有招聘、引流话术。
- 平台以小红书为主，换到抖音要重新验证。
- 需要判断预算规模、要不要上头部达人时，搭配 `baipai-to-brand`；需要让用户敢下第一单时，搭配 `lemon-market-trust`。
