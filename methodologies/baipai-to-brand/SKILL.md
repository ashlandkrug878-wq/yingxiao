# 白牌 → 品牌：00 准入判断 + 01–06 六步路径

方法论来源：好望水前操盘手的抖音分享（千万级 → 亿级）。核心观点：品牌不是赌单个爆款，而是一步步搭体系、攒认知；体系跑通之后，从 0 到 1 就只是规模放大的问题。

结构：
- **00 准入判断**：这个品牌能不能做、值不值得做品牌。只做判断，不做执行。
- **01–06 六步路径**：通过准入后按顺序执行。
- **阶段时间线**：品牌在哪个规模，应该做到第几步。

## 使用方式

1. **先过 00**：逐条给出 通过 / 有风险 / 不通过，并附理由。产品底子不通过就停下，只给产品改进建议。
2. **定位阶段**：根据营收、利润、现金流、可用品牌预算，对照"阶段时间线"判断品牌处在 ①–⑤ 的哪一档，以及这一档应该做到第几步。
3. **找卡点**：对照 01–06 的完成标志，找出第一个没完成的步骤（即卡在第几步），以及前面步骤留下的欠账。
4. **给动作**：输出卡点这一步最该做的事，以及进入下一步的标志。

- 默认在对话里直接给结论和建议，用户明确要求时才生成文档或方案表。
- 信息不够时，最多问 3 个最关键的问题（优先问：年营收和是否盈利、可用品牌预算、产品复购和差评情况），其余信息先做合理假设并说明。
- 也可以只用 00 做客户筛选：判断哪些品牌值得投入策略资源做深度服务，哪些只适合按单走量。
- 配套的自诊断网站数据在同目录的 `diagnosis.json`，两者内容需保持一致。

## 00 准入判断：是否能成为品牌

原分享者就是用这三条挑选要加入哪家公司的。三条的优先级不同：产品底子是一票否决，另外两条可以补救。

| 判断项 | 判断什么 | 不通过怎么办 | 通过后在哪一步落地 |
|---|---|---|---|
| 产品底子（一票否决） | 自己作为消费者愿不愿意买？过去的销量是不是靠夸大功效做起来的？ | 停止，先改产品，所有营销动作都不做。流量越大，反噬越快 | 01 把品质证明做出来 |
| 预算与基建 | 品牌预算能否到营收的 7%–10%？是否还在生死线上？承接基础缺什么？ | 停在生死线，只做不花钱的优化 | 01 补齐视觉、故事、承接 |
| 老板思维 | 能不能接受长线种草，而不是要求即时 ROI？ | 先对齐认知，否则后面的投放会被即时 ROI 砍掉 | 02 把三组指标定成考核体系 |

原则：很会做营销不是贬义词，营销的本质是让好产品被更多人看见，不能用来掩盖产品问题。

说明：原分享里预算的说法混用了营收口径和利润口径，使用前要和用户确认。

## 01 补基础：流量来了接得住

- 生死线时只做不花钱的优化：主图视频、详情页、店铺首页、官网。
- 有预算后，第一笔钱花在：
  - 视觉审美：搜索品牌名时，不能是"AI 漫剧 / 卖惨故事"式的包装，要有品牌感。
  - 品牌故事和品牌理念：店铺首页和账号主页上要有。
  - 品质证明：工厂实拍、溯源、检测报告等。
- 完成标志：用户点进来的第一印象"像一个品牌"。

## 02 转认知：老板思维从即时 ROI 转向三组指标

- 品牌的逻辑是先种草：今天花 1 块，结合内容和整体流量，3 个月左右赚回 3 块。不是不看 ROI，而是用下面这三组指标去预估 ROI。
- 三组指标就是新的考核体系：
  - 心智指标：品牌搜索词的增长、品类词里品牌的占比、用户会不会主动搜索。
  - 互动指标：评论区有没有真实用户问"在哪买"，产品被提及的程度如何。
  - 后链路指标：搜索成交的增长、种草带来的直播间 ROI 增长、自然流成交的增长。
- 完成标志：老板和团队用这三组指标审视投放，而不是只看单条的即时产出。

## 03 建组织：策略判断收回内部

- 内部至少要有一个"策略大脑"，能判断什么内容是消费者真正认可的。
- 不把宝全押在 MCN 上。靠返点赚钱的代理方会倾向推荐返点高、档期空、走单快的达人，而真正种草效率高的达人往往返点低、需要排期。
- 少而精：比如一个月只做 20 条，每条都有明确目的。二八法则：20% 的优质达人贡献 80% 的有效产出。
- 如果用户本身就在 MCN 或代理方：把这一步转化为"如何以策略方而非返点方的角色服务品牌"。
- 完成标志：内容和达人的选择由内部判断，外部只负责执行。

## 04 做调研：找到真正的卖点

**竞品投放复盘**（工具：飞瓜、灰豚、巨量算数、蒲公英等）
- 竞品近一年投了哪些类型的达人，各层级的达人数量分别是多少。
- 从年初到年底一直在打的卖点是什么，中途怎么变化。
- 判断标准：能持续放量的卖点就是被验证过的卖点，能一直复用的内容形式就是转化率最高的形式。
- 跨品类借鉴：如果本品类的投放水平普遍偏弱，就去看内容能力更强的品类（如美妆护肤）怎么表达卖点。

**评论区分析**（可以用 AI 批量分析多个平台的评论）
- 好评高频词 → 用户购买的理由
- 差评或抱怨 → 没被满足的需求
- 两者交叉 → 主攻卖点

- 完成标志：明确最有效的场景、人群、卖点、内容形式。

## 05 出策略：brief → 测试 → 放大

**三句话 brief**：小学生都能看懂，能在微信对话框里说清楚。不要几十页的 PPT，也不要几百行 AI 生成的文字。
```
场景：____（在什么场景下用）
核心卖点：____（只说一个）
让用户记住：____（看完后脑子里留下的那一句话）
```
避免一上来就讲技术或原理，因为用户一旦认定"这是广告语"，就会自动屏蔽这条信息。

**先测试**
- 测试预算：总预算的 15%–20%。
- 测达人类型：先用腰部达人和起号期达人（单条合作几千到一万左右），这类达人档期松、内容有自己的章法，能快速跑完一轮。
- 测内容形式：场景型 / 测评型 / 剧情种草型，用 02 的三组指标比较种草效率。

**再放大**
- 测出最优形式后，集中预算放大这一种打法。
- 剧情类合作的三条标准（原案例跑出来的最优解）：
  1. CPM 在目标线以内（原案例是 10 以内，必须按当前行情重新校准）；
  2. 剧情讲得好；
  3. 产品推动剧情发展：没有这个产品，故事就不成立，不能只是道具式植入。
- 剧情类内容的好处：生命周期长（半年左右持续带流量），以故事形式进入用户记忆。

**按单次投放预算配置头部达人**
| 单次投放预算 | 配置 |
|---|---|
| 100 万以内 | 不碰头部达人和明星，单条费用会挤占铺量预算 |
| 200–300 万以上 | 配 1–2 个头部达人：给品牌做背书（评论区出现"这不是 XX 推荐过的吗"），也给全平台的达人提供素材 |

- 完成标志：各平台跑出稳定的爆款，搜索成交和自然流成交明显增长。

## 06 成品牌：认知 → 好感 → 忠诚

触发信号：各平台都有爆款，但用户记住的是达人，不是品牌，单点爆款撑不起品牌心智。

- 原则：让用户记住"品牌做了什么事"，而不是"品牌和哪个达人合作了"。
- 结构：节点（节日或热点）+ 产品适合这个场景 + 一件有温度、可传播的具体行动 + 三端承接（达人端 → 品牌端 → 直播间）。
- 参考案例：年货节时准备 1 万份年货送给工地打工的人，由 1000 位摆摊博主去送，几十万预算冲进全站前三；霸王茶姬在郑钦文夺冠时做买一送一，并给全员发奖金。
- 对应 AIPL 模型（认知 → 兴趣 → 购买 → 忠诚），忠诚这一层靠品牌行为来解决。

事件方案模板：
```
节点：
要传递的品牌认知（一句话）：
具体行动（谁、给谁、做什么、规模）：
达人端怎么参与：
品牌端怎么发声：
直播间/店铺怎么承接：
衡量指标：品牌搜索、话题声量、自然流成交
```

## 阶段时间线：每个规模做到哪一步

标注为（原文）的是分享者的原话，（推算）是按品牌预算约占营收 7%–10% 的比例推出来的，使用时要把两者区分开告诉用户。营收只是参考坐标，真正决定阶段的是"有没有可用于长线投入的预算"和"前面的步骤是否完成"。

| 阶段 | 规模 | 品牌预算 | 应做到 | 不该做 |
|---|---|---|---|---|
| ① 生死线 | 未稳定盈利、现金流紧张 | 约为 0 | 00 的产品底子判断 + 01 中不花钱的部分（原文） | 任何花钱的品牌动作 |
| ② 千万级 | 营收约 1000–3000 万 | 年约 70–300 万（推算） | 00 全部通过；01–04 做完；05 小额测试 | 头部达人、明星、大规模铺量 |
| ③ 五千万级 | 营收 5000 万以上 | 年约 500 万（原文） | 05 测出打法后集中放大；单次 100 万以内不碰头部 | 只看即时 ROI；分散尝试太多打法 |
| ④ 亿级前后 | 营收约 1 亿以上 | 单次投放 200–300 万以上 | 05 配头部做背书；开始尝试 06 | 只靠单点爆款支撑心智 |
| ⑤ 品牌心智期 | 亿级以上 | — | 06 节点化事件营销，经营到忠诚 | 让用户只记住"品牌和谁合作了" |

## 输出结构（诊断时默认采用）

1. **00 准入结论**：三条各自的 通过 / 有风险 / 不通过，以及总结论（能做 / 补救后能做 / 不建议做）。
2. **所处阶段**（①–⑤）及判断依据。
3. **卡在第几步**：01–06 中第一个没完成的步骤，以及前面步骤留下的欠账。
4. **卡点这一步最该做的 3 件事**（具体到动作），以及这个阶段不该做的事。
5. **进入下一步的标志**，用 02 的三组指标来衡量。
6. **需要警惕的风险**。

## 使用时的提醒

- 原方法论来自饮料品类和 2021–2023 年抖音剧情内容红利期。剧情号最优、CPM 10 以内等结论应当作需要测试的假设，不是常数。
- 阶段时间线里的营收档位大多是推算的。客单价、毛利率不同，可用的品牌预算也不同，所以要以"可用于长线投入的预算"为准，不要机械套用营收数字。
- 客单价高、需要讲功能或专业性的品类，测评型和专家型内容的权重可能更高，要靠 05 的测试来定。
- 存在幸存者偏差：给建议时要说明哪些是案例经验，哪些是普遍原则（例如产品底子优先、先测后放、用三组指标替代即时 ROI）。
